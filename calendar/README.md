# bikram-sambat-calendar

This package is a fork of [leapfrogtechnology/nepali-date-picker](https://github.com/leapfrogtechnology/nepali-date-picker) (originally licensed under the ISC License), modified to delegate all calendar calculations directly to the [bikram-sambat](https://github.com/medic/bikram-sambat) core library.

## Compliance and Attribution

* **Original Codebase Copyright**: Copyright (c) 2018 - current, Leapfrog Technology (ISC License).

All date calculations (month lengths, Gregorian-to-BS conversion, BS-to-Gregorian conversion) have been refactored to use the `bikram-sambat` library.
